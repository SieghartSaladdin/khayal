# Review sheet

Add one block per ID to `testing/benchmark/REVIEW.md`, filled in by the **user**, not the agent. Leave the user's fields empty. Write the labels in the user's language.

Scale: 1 = poor, 5 = ready to publish.

```
## <ID> · <technique and level>
- Capable?: yes / partly / no
- Looks (1-5):
- Not generic (1-5):
- Smoothness (1-5):
- Notes (what is broken, ugly, or good):
- Agent measurements: see <ID>/RESULT.md
```

Checks to suggest to the user while reviewing: try every control, shrink the window to phone width, press Tab to use the keyboard, and notice whether anything feels heavy.

## Closing section, once per round

```
## Conclusion
- Technique worth offering by default:
- Technique only for specific cases (name the case):
- Technique not to offer to users:
- Technique to test next:
```
